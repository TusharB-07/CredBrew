# Font Files

Bundled TrueType fonts used by the render engine (svg → PNG).

- `NotoSans-Regular.ttf`
- `NotoSans-Bold.ttf`

Source: https://github.com/notofonts/noto-fonts (hinted/ttf/NotoSans)
Version: Noto Sans v2.008

License: SIL Open Font License 1.1 (OFL-1.1). https://openfontlicense.org

No additional font files are required to build or run the render engine.
